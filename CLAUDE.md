# Pointscape

A flat 2D web remake of the "Pointers" (Arrows) puzzle from Offline Games 3.16.1. Tap an arrow whose path out of the
board is clear, and it slides away. A blocked tap costs a heart. Clear the board to win. Five board sizes (Tiny 16x16,
Compact 24x24, Large 32x32, Vast 48x48, Massive 64x64), 200 levels each, 1,000 in total. Boards packed with arrows,
with rotating shape masks. There is no 3D, no layers, and no Undo anywhere.

Design documents, in reading order: `docs/superpowers/specs/2026-11-11-pointscape-design.md` (spec),
`docs/superpowers/plans/2026-11-11-pointscape.md` (plan). `docs/` is gitignored, so design files exist only on the
owner's machine and are not on GitHub.

## Environment

- Node 24, pinned in `.nvmrc`. Package manager: npm.
- Stack: React, TypeScript (`strict`), Vite, Tailwind CSS v4, Vitest, ESLint, Prettier.
- Published as static files on GitHub Pages by `.github/workflows/deploy.yml` on push to `main`. `vite.config.ts` sets
  `base` to `/pointscape/`. The repository's Pages source must be "GitHub Actions".
- Local-only, gitignored: `docs/`, `.superpowers/`, `.claude/`, `.husky/_`. A fresh clone has `.husky/commit-msg`
  tracked and `npm install` runs `husky`.
- Shell note: the owner's shell wraps `npm` and `npx` in Safe-chain, which can time out on installs with "Failed to
  check for malicious packages". Run `command npm install ...` or `command npx ...` to bypass it, but only with the
  owner's approval.

## Commands

- `npm run dev`: dev server. The developer unlock-all switch is only available here.
- `npm run build`: type check, then production build to `dist/`.
- `npm test`: Vitest, once. `npm run test:watch` for watch mode.
- `npm run lint`, `npm run format:check`, `npm run format`. Prettier ignores `docs/` and `.superpowers/`.

## Architecture

Four layers. Dependencies point downward only.

- `src/core/`: pure game logic. No React or browser APIs. Grid, shape masks, arrow rules, free-arrow test, solver,
  seeded level generator. Fully unit tested.
- `src/game/`: state, progress, settings, `isUnlocked()`, hint gifts, web worker level loader, `localStorage`
  saving (`pointscape:v1`).
- `src/view/`: HTML canvas 2D rendering, pan, zoom, arrow exit/bump/flash animations, synthesized sound.
- `src/ui/`: React screens, modals, HUD, and dialogs.

## Key decisions

- Flat 2D rendering on HTML canvas; no 3D, no three.js, no layers.
- A level is generated by reverse construction, so it is always solvable. Levels are seeded, so Try again and Restart
  give the same level.
- Every unlock rule goes through `isUnlocked()`. The UI never reads the developer flag itself.
- Clearing 10 levels of a size opens the next size. Tiny is open from the start.
- First 10 levels of each size use a plain square board; from level 11 shapes rotate.
- Player name: asked once, random animal name if skipped, editable in Settings, never cleared by Reset progress.
- Sound is synthesized with Web Audio in `src/view/sound.ts`. No audio files ship.
- Storage key: `pointscape:v1`.

## Conventions

- Tailwind only, canonical class names, no CSS files besides the Tailwind entry (`src/index.css`, which holds the
  `@theme` colour tokens). `eslint-plugin-better-tailwindcss` enforces canonical classes in `.tsx` files, and
  `npm run lint -- --fix` fixes them. Its line-wrapping rule is off because Prettier owns wrapping.
- No `any` in TypeScript. `tsconfig.json` is `strict` plus `noUncheckedIndexedAccess`.
- Commits follow `type(scope): summary` and are checked by commitlint. Owner exception for this project: committing
  directly to `main` is allowed, so the global protected-branch rule does not apply here. Still commit only when asked.
- Do not add Claude or Anthropic co-author lines to commits or pull requests.
